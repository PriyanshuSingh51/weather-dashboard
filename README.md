# 🌤 Weather Dashboard

A modern and responsive weather dashboard built using **HTML, CSS, and JavaScript** with the **OpenWeatherMap API**. The application provides real-time weather information, 5-day forecasts, temperature conversion, dark mode, and an interactive user experience.

## 🚀 Features

* Real-time weather updates
* Search weather by city name
* 5-Day weather forecast
* Temperature unit conversion (°C / °F)
* Current weather conditions
* Humidity, Wind Speed, and Pressure details
* Dynamic weather icons
* Dark Mode support
* Loading spinner and error handling
* Responsive design for mobile, tablet, and desktop
* Enter key search functionality
* Clear search option
* Interactive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* OpenWeatherMap API

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/your-username/weather-dashboard.git
```

2. Navigate to the project folder:

```bash
cd weather-dashboard
```

3. Create an OpenWeatherMap API key.

4. Open `js/config.js` and add your API key:

```javascript
const API_KEY = "YOUR_API_KEY";
```

5. Run the project using VS Code Live Server.
